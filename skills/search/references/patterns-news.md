# Query Patterns: News and Recent Events

```
WebSearch { "query": "category:news [topic] announcement", "numResults": 15 }
WebSearch { "query": "[topic] news update latest development [month year]", "numResults": 15 }
```

For reactions/sentiment on recent events, search across platforms:
```
WebSearch { "query": "[event] reaction analysis commentary", "numResults": 12 }
WebSearch { "query": "[event] criticism concerns issues bugs", "numResults": 15 }
```
